This console doesn't know what "category" or "value" means — it detects shape at runtime. Paste JSON (array of key/value objects), plain Label: value blocks, or two-column CSV, and it relabels the fields to match whatever your source calls them. If you add a new datasource feeding the DB, or swap the API entirely, point the URL field below at its endpoint and this view redraws around it.

Every load reads live through /api, which calls straight into reader.py — Postgres row → SHA-256 of category and value, same as it's always done. Nothing here caches or rewrites what the database hands back.
